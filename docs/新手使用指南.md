# 桌面灵伴新手使用指南

这份说明写给第一次使用 Gitee 或 GitHub、也没有 Python 或编程经验的用户。只想使用桌面宠物时，不需要下载源码，也不需要在命令行里输入任何内容。

## 一、我到底该下载哪个文件？

选择任意一个站点直接下载，两个安装包内容相同：

- [Gitee：DesktopCompanion-2.4.6-setup.exe](https://gitee.com/legender134/desktop-companion/releases/download/v2.4.6/DesktopCompanion-2.4.6-setup.exe)
- [GitHub：DesktopCompanion-2.4.6-setup.exe](https://github.com/Legender134/desktop-companion/releases/download/v2.4.6/DesktopCompanion-2.4.6-setup.exe)

如果你是从 Gitee 仓库首页进入：

1. 打开仓库的[发行版页面](https://gitee.com/legender134/desktop-companion/releases)。
2. 点击最新的 `桌面灵伴 2.4.6`。
3. 在“下载”区域点击 `DesktopCompanion-2.4.6-setup.exe`。

如果你是从 GitHub 仓库首页进入：

1. 点击右侧的 **Releases**，或点击首页的“下载最新版安装程序”。
2. 打开最新的 `桌面灵伴 2.4.6`。
3. 展开页面底部的 **Assets**。
4. 点击 `DesktopCompanion-2.4.6-setup.exe`。

以下文件不是普通用户的安装程序：

- 名称中带有 `Source`、`Source code` 或“源代码”的压缩包：给开发者看的源码；
- `Source code (zip)`：GitHub 自动生成的源码；
- `Source code (tar.gz)`：GitHub 自动生成的另一种源码压缩包；
- `SHA256SUMS.txt`：用于校验下载文件；
- `安装说明.md` 或 `INSTALL-zh-CN.md`：可以离线阅读的中文说明。

## 二、怎样安装？

1. 双击刚下载的 `DesktopCompanion-2.4.6-setup.exe`。
2. 按安装向导继续。
3. 如果不希望电脑开机时自动运行，可以在向导里取消“开机启动”。
4. 安装完成后，可以立即运行，也可以双击桌面上的“桌面灵伴”快捷方式。

安装位置默认为：

```text
%LOCALAPPDATA%\Programs\DesktopCompanion
```

这是当前用户目录，不需要管理员权限。若浏览器、安全软件或公司电脑策略阻止运行，请先确认文件来自本仓库并核对 SHA256；不要为了安装而关闭系统安全功能。

## 三、第一次启动后在哪里？

- 宠物默认出现在主屏幕右下方、任务栏上方。
- 屏幕右下角会出现托盘图标。
- Windows 11 可能把托盘图标放在 `^` 隐藏图标区域，点开 `^` 就能看到。
- 双击托盘图标可以重新显示宠物。
- 右键宠物或右键托盘图标，可以打开完整菜单。

## 四、最常用的操作

| 操作 | 效果 |
|---|---|
| 左键单击宠物 | 随机做一个原地动作 |
| 左键双击宠物 | 跳跃 |
| 左键按住并拖动 | 移动宠物位置 |
| 中键单击 | 随机动作 |
| 右键单击 | 打开完整菜单 |
| 托盘图标双击 | 显示并激活宠物 |
| 托盘图标右键 | 打开完整菜单 |

右键菜单里可以切换十一、紫灵、南宫婉或自己安装的宠物，也可以调整大小、动画速度、移动速度、自动闲逛、看向鼠标、注视方式、自主小动作、开机启动和始终置顶。

如果不知道某一项有什么作用，先勾选菜单里的“显示详情”。这时每一项右边都会出现一个圆形 `?`，把鼠标放进圆圈后说明会立即显示，不需要停留等待；停在菜单文字上不会遮挡操作。这里不是一句笼统介绍：它会明确列出“安静 / 标准 / 活跃”的 8–18 / 2–6 / 1–3 秒，普通移动的 75 / 120 / 180 像素/秒，动画速度倍率，以及当前宠物每个动作的帧数、毫秒数、总时长、自动权重、概率和冷却。看懂后再点一次“显示详情”，圆形问号和说明就会收起。程序会记住你的选择。

“动作展示”会连续播放当前宠物的全部原地动作。“注视方式”推荐选择“鼠标活动时”：鼠标静止约 8 秒后，宠物会按“自动闲逛”和“自主小动作”的勾选状态自行活动，鼠标再次移动就恢复看向鼠标；选择“始终看向鼠标”则不会自动交接这些行为。

## 五、怎样切换宠物？

1. 右键宠物或右键托盘图标。
2. 打开“切换宠物”。
3. 点击“十一”“紫灵”或“南宫婉”。

切换后，宠物外观、动作名称、托盘图标和托盘提示名称都会一起变化。

## 六、怎样更新到新版本？

1. 退出正在运行的桌面灵伴，或直接运行新版安装程序。
2. 从 [Gitee 发行版](https://gitee.com/legender134/desktop-companion/releases)或 [GitHub Releases](https://github.com/Legender134/desktop-companion/releases)下载版本号最高的 `DesktopCompanion-<版本号>-setup.exe`。
3. 像第一次一样安装即可覆盖更新。

覆盖安装会保留设置和自己添加的宠物。为了防止误操作，重要的自制宠物仍建议单独备份。

## 七、怎样卸载？

打开 Windows：

```text
设置 → 应用 → 已安装的应用 → 桌面灵伴 → 卸载
```

卸载会删除程序、设置、日志和用户宠物目录。若安装过自制宠物，请先备份：

```text
%APPDATA%\DesktopCompanion\pets
```

十一桌面宠物 1.0 与桌面灵伴 2.x 使用不同目录，可以同时存在；卸载桌面灵伴 2.x 不会删除 1.0。

## 八、想添加自己的宠物怎么办？

桌面灵伴不能把任意一张图片直接变成完整宠物。一个宠物包至少需要：

```text
你的宠物ID\
├─ pet.json
└─ spritesheet.webp
```

新版 v3 图集允许动作数量、帧数和图集行列动态变化。请从[添加新宠物指南](添加新宠物指南.md)开始；制作时可复制仓库里的 [`examples/pet-pack-template`](../examples/pet-pack-template) 模板。精确尺寸和校验规则见 [v3 动态宠物包技术规范](pet-pack-format-v3.md)，旧宠物仍可使用 [v2 兼容格式](pet-pack-format-v2.md)。

## 九、常见问题

### 找不到宠物

先点开右下角 `^`，右键桌面灵伴托盘图标，选择“回到屏幕中央”。仍然看不到时，退出后重新启动。

### 没有托盘图标

Windows 11 常把新图标放进 `^` 隐藏区域。若隐藏区域也没有，尝试从桌面快捷方式再次启动；程序只允许一个实例，第二次启动会激活已有宠物。

### 数字快捷键没有反应

确认右键菜单中的“悬停数字快捷键”已开启，并把鼠标放在宠物身体的不透明区域上。鼠标不在宠物身上时，数字键会正常输入到其他程序。

### 新宠物没有出现在菜单中

确认宠物文件夹中同时存在 `pet.json` 和 `spritesheet.webp`，文件夹名与 JSON 的 `id` 完全相同，然后右键选择“重新扫描宠物”。详细排错见[添加新宠物指南](添加新宠物指南.md#九新宠物没有出现时怎么排错)。

## 十、怎样核对安装程序？

桌面灵伴 2.4.6 安装程序 `DesktopCompanion-2.4.6-setup.exe` 的 SHA256 是：

```text
D451BC1FB6D548892D6F10C46BB9AE92BFECACDA3DFC3F6F5AB2BC530A09AE9C
```

可在 PowerShell 中运行：

```powershell
Get-FileHash -Algorithm SHA256 .\DesktopCompanion-2.4.6-setup.exe
```

输出应与 Release 中的 `SHA256SUMS.txt` 一致。

## 隐私说明

桌面灵伴没有账号、广告、遥测或自动更新，不主动发起网络请求。设置和日志只保存在当前用户目录。数字快捷键只在鼠标命中宠物时判断 `0–9`，不记录输入内容。
