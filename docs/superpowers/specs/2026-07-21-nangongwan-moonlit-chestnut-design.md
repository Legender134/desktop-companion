# 南宫婉“月下含栗”动作设计

日期：2026-07-21

状态：已由 `2026-07-21-nangongwan-moonlit-chestnut-redesign.md` 取代；本文件仅保留 2.4.1 历史设计记录

适用范围：桌面灵伴内置宠物“南宫婉”

## 1. 目标

为桌面灵伴版南宫婉新增一个具有角色辨识度的招牌动作“月下含栗”。动作以动画中的月下屋檐远景、紫色御物灵光和含栗镜头为依据，通过适合桌面宠物的柔和推镜重新组织，而不是逐镜复制影视剪辑。

完成后应满足以下结果：

- 用户可以从右键动作菜单随时播放“月下含栗”。
- 开启“自主小动作”后，“月下含栗”以约 `1/20` 的基础概率参与随机触发。
- 动作使用 36 个有效画面、正常速度约 9.1 秒，并在结束后自然回到原有待机状态。
- 旧“栗糕轻尝”素材继续保留，但退出菜单和普通随机动作池，等待未来设计独立的彩蛋触发方式。
- 新动作只使用动画已经明确表现的月夜、屋檐、栗糕和紫色御物灵光，不添加与南宫婉无关的虚构法术。

## 2. 范围边界

本次包含：

- 桌面灵伴 v3 南宫婉图集和 `pet.json`。
- “月下含栗”的画面、时序、菜单入口和自主动作权重。
- “动作展示”队列对既隐藏又停用自动触发动作的过滤规则。
- 与资源契约、菜单、随机动作和冻结程序相关的自动测试及人工验收。
- 新动作对应的版本说明与动作说明。

本次不包含：

- Codex 宠物版南宫婉。
- 旧“栗糕轻尝”的最终彩蛋触发条件。
- 新的动画渲染能力或新的宠物包格式版本；只允许为隐藏旧动作增加一项窄范围的“动作展示”过滤修正。
- 音效、台词、对话框或桌面背景替换。
- 对其他南宫婉动作画面的重绘。

## 3. 动画依据

主要依据为哔哩哔哩国创发布的《凡人修仙传之慕兰之战》第 3 集预告（总第 179 集预告）：

- `16.56–22.68` 秒：大满月、建筑屋檐和南宫婉剪影构成远景，约 6.12 秒。
- `22.68–25.84` 秒：手部近景，紫色灵力托起金黄色栗糕，约 3.16 秒。
- `25.84–28.12` 秒：栗糕被送至唇边，约 2.28 秒。

公开来源：<https://www.bilibili.com/video/BV11hE16WEma>

旧动画第 29 集已经建立南宫婉爱吃栗子的角色梗；新动作应当延续这一辨识点，但采用当前蓝银元婴期造型和最新镜头里的御物方式。

供本地逐帧研究使用的短预告存放在被 Git 忽略的 `private-reference/nangong-wan/latest-model-2026/`，不得打入安装包、发布附件或宠物资源目录。

## 4. 视觉设计

### 4.1 总体构图

动作使用三级构图，并保持动画原片中月轮随镜头尺度变化的关系：

1. **A 远景**：淡蓝白满月以完整或接近完整的圆轮出现在屋檐后方，深蓝屋檐从右下方伸向画面中部，南宫婉以小比例剪影侧坐在翘起的檐角。
2. **B 坐姿中景**：人物约占画面高度的六成，仍侧坐在飞檐最外缘；月轮随推镜放大并越出画面，只显示巨大的局部月面和弧边，不再显示完整圆轮。
3. **C 手部/嘴部特写**：裁至上半身、手、栗糕和侧脸；依照原片不再显示月轮，只保留冷色月光。脸、手和栗糕在桌面常用尺寸下均需可辨认。

动作从 A 远景开始，以单镜头推近让完整月轮逐步放大、越出画面，再依照原片干净切入 C 特写；完成品尝后回到巨大局部月面下的 B 坐姿，最后退回 A 远景并淡出。镜头切换不得使用半透明双图叠化，以免出现双人重影。

### 4.2 人物和道具

- 人物使用现有南宫婉最新蓝银造型，发饰、银色护腕、蓝色袖口和耳饰保持一致。
- 姿态为面向画面左侧、双腿自然垂在檐外的侧坐，位置固定在翘起的屋檐尖端；不改成站立、盘腿悬空或普通椅坐。
- 栗糕使用动画中的金黄色、有细纹的小块造型，不画成棕色圆栗子。
- 抬手、御物和送至唇边均使用右手；手指动作轻而克制，不做夸张挥臂。
- 品尝阶段只表现轻含栗糕、一次眨眼和很淡的满足神情，不使用明显咬断、大幅咀嚼、鼓腮或卡通化表情。

### 4.3 场景和特效

- 月亮为带柔边的淡蓝白半透明月轮，不使用不透明圆形贴片；A 远景显示完整圆轮，B 中景只显示放大后越界的局部月面，C 特写不显示月轮。
- 屋檐为深蓝黑色，仅保留足以识别中式檐角的瓦当、翘角和一段屋脊。
- 薄雾只在月轮和屋檐附近缓慢漂移，不能遮挡脸或栗糕。
- 紫色灵力先在指间形成微弱光点和细环，再托住栗糕沿短弧线移动；颜色参考最新动画，不加入雷电、法阵、花瓣或轮回神光。
- 所有场景元素都绘制在透明画布中，帧边缘必须渐隐，不能出现方形夜空背景块。
- 远景阶段即使人物较小，也要通过月轮廓光保持发型、袖摆和坐姿剪影的辨识度。

## 5. 36 帧分镜与时序

正常动画速度下使用以下逐帧时长，总计 `9100 ms`：

```json
[180, 180, 220, 300,
 260, 300, 420, 500,
 150, 150, 160, 170, 180, 220,
 180, 220, 200, 240,
 140, 150, 170, 190, 260,
 140, 150, 170, 190, 260,
 260, 350, 500,
 450, 650,
 220, 260, 360]
```

| 帧 | 阶段 | 画面和运动 | 阶段时长 |
|---|---|---|---:|
| 1–4 | 场景显现 | 月光、薄雾和屋檐从透明状态渐显 | 880 ms |
| 5–8 | 月下远景 | 南宫婉以剪影侧坐檐角，发尾和袖摆微动 | 1480 ms |
| 9–14 | 连续推近 | 完整月轮随镜头快速放大，圆轮边缘逐步越出画面，切入飞檐边缘坐姿中景 | 1030 ms |
| 15–18 | 坐姿中景 | 巨大局部月面位于身后；呼吸起伏、抬起右手，视线落向指前 | 840 ms |
| 19–23 | 御物摄栗 | 干净切入不显示月轮的上半身特写；指间聚起紫色微光，栗糕浮起并稳定悬停 | 910 ms |
| 24–28 | 送至唇边 | 在无月轮特写中，栗糕沿短弧线靠近指尖，再随手势移向唇边 | 910 ms |
| 29–31 | 轻尝回味 | 嘴部与手部特写不显示月轮；轻含栗糕、眨眼，出现很淡的满足神情 | 1110 ms |
| 32–33 | 抬眸望月 | 回到巨大局部月面下的飞檐坐姿，右手放低并抬眸 | 1100 ms |
| 34–36 | 退远淡出 | 镜头退回 A 远景，人物、屋檐和月光渐隐 | 840 ms |

36 帧必须是连贯的有效关键画面，不得用完全相同的静止帧凑数。允许在停留阶段保持身体主姿态，但发丝、袖摆、呼吸、雾气、月辉或眼神至少有一项发生可见的微小变化。

## 6. 资源布局

当前南宫婉 v3 图集使用 `192 × 208` 的单元格、16 列，现有尺寸为 `3072 × 4784`，共 23 行。行号和列号均从 0 开始；新动作从第 23 行第 0 列开始，连续使用 36 个单元格：

- 第 23 行第 0–15 列：第 1–16 帧。
- 第 24 行第 0–15 列：第 17–32 帧。
- 第 25 行第 0–3 列：第 33–36 帧。
- 第 25 行第 4–15 列保持完全透明，供未来动作使用。

图集完成后的尺寸为 `3072 × 5408`。现有 v3 坐标解析已经支持动作跨行连续读取，单动作上限为 64 帧，因此不修改引擎或资源格式。

## 7. 动作配置

新增动作的逻辑配置为：

```json
"moonlitChestnut": {
  "label": "月下含栗",
  "role": "interaction",
  "row": 23,
  "frameCount": 36,
  "frameDurations": [
    180, 180, 220, 300,
    260, 300, 420, 500,
    150, 150, 160, 170, 180, 220,
    180, 220, 200, 240,
    140, 150, 170, 190, 260,
    140, 150, 170, 190, 260,
    260, 350, 500,
    450, 650,
    220, 260, 360
  ],
  "repeatCount": 1,
  "autoplayWeight": 5,
  "cooldownMs": 90000,
  "showInMenu": true
}
```

为在不改变其他动作相对概率的前提下得到约 `1/20` 的基础概率，实施时将除旧“栗糕轻尝”之外的现有互动动作权重统一乘以 3；它们彼此之间的概率关系保持不变。其他可自动播放互动动作的总权重为 96，新动作权重为 5，因此未考虑冷却、禁止连续重复和动作分组过滤时的基础概率为：

```text
5 / (96 + 5) = 4.95%，约等于 1/20
```

移动和遁光动作使用独立的闲逛选择池，其权重不得随之修改。术法组的“连续两次不播放同组动作”规则继续生效，因此实际长期出现频率允许围绕 `1/20` 小幅波动。

旧 `tasteCake` 动作保持原来的行号、10 帧画面和逐帧时长，但：

- 删除 `autoplayWeight`，使其不进入自主动作池；当前格式不接受显式的零权重。
- 将 `showInMenu` 改为 `false`，使其不出现在右键动作菜单。
- “动作展示”只收集 `showInMenu=true` 或 `autoplayWeight>0` 的互动动作，因而不播放既隐藏又停用自动触发的 `tasteCake`；其他隐藏自主动作仍照常参加展示。
- 不删除动作定义和图集单元格，未来彩蛋逻辑可以直接触发该动作。

## 8. 播放和中断规则

- 菜单手动播放不受 `90000 ms` 自动冷却限制。
- 自主播放完成后按现有行为控制器恢复待机，并重新安排下一次自主动作。
- 用户拖动宠物、切换宠物或退出程序时沿用现有中断逻辑，不为本动作增加不可中断状态。
- 动作播放期间不触发鼠标注视覆盖，避免眼神方向破坏分镜；动作结束后恢复用户原有注视设置。
- 动画速度设置继续对全部逐帧时长使用现有倍率，不另设专用速度。

## 9. 验证标准

### 9.1 自动测试

- 南宫婉动作数量由 20 个增加到 21 个，总帧数由 238 增加到 274。
- 图集为 `3072 × 5408`、RGBA WebP，并能由 Qt WebP 插件正确解码。
- `moonlitChestnut` 的 36 个单元格均含有效 alpha，第 25 行第 4–15 列保持透明。
- `frameDurations` 数量严格等于 36，总时长严格等于 `9100 ms`。
- `moonlitChestnut` 出现在菜单、自主动作池和“动作展示”队列；`tasteCake` 不出现在这三个普通入口中，但仍能由动作 ID 解析并播放。
- 权重池在未应用动态过滤时，`moonlitChestnut` 的基础概率为约 4.95%。
- 动作时间轴播放完第 36 帧后返回待机，不越界、不循环。
- 冻结程序自检仍能识别南宫婉资源并加载全部宠物。

### 9.2 人工视觉验收

- 在 75%、100%、125% 三档宠物尺寸下，B 主景中的脸、手势和栗糕均能辨认。
- A 远景能一眼看出“满月、屋檐、檐角坐姿”，但场景不会撑大或移动宠物窗口。
- A 到 B 的连续推镜能看出月轮由完整圆面放大为越界局部；B/C 的干净切镜无半透明双人重影，C 特写不出现月轮。
- 紫色灵力始终围绕栗糕和手指，不遮挡眼睛、嘴唇或服装纹样。
- 透明边缘无黑边、白边、方形底色或 WebP 压缩脏块。
- 连续手动播放三次没有位置漂移；正常自动播放不会与拖动、闲逛或注视状态冲突。
- 36 帧中不存在完全相同、仅用于凑数的连续画面。
