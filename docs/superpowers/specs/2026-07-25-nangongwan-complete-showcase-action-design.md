# 南宫婉完整动作展示设计

## 目标

把已经验收的南宫婉纯动作展示视频中的整套内容，按相同顺序和节奏封装为桌面灵伴中的一个有限动作。用户切换到南宫婉后，可以从右键动作菜单选择“完整动作展示”，一次连续看完全部历史阶段；该动作不会由“自主小动作”随机触发，也不会被通用“动作展示”再次收录。

本功能只进入桌面灵伴版南宫婉宠物包。现有动作、月下屋檐常驻状态、历史 WebP、视频文件及其他宠物均保持不变。

## 用户入口与播放行为

新增动作：

```json
{
  "completeShowcase": {
    "label": "完整动作展示",
    "role": "interaction",
    "row": 34,
    "startColumn": 0,
    "frameCount": 448,
    "frameDurations": ["由构建器按30fps时间线生成的448个整数毫秒值"],
    "repeatCount": 1,
    "autoplayWeight": 0,
    "showInMenu": true,
    "includeInShowcase": false
  }
}
```

- 右键菜单直接显示“完整动作展示”。
- 仅允许用户手动触发；“自主小动作”和“随机动作”都不会抽到它。
- 正常速度下总时长为82433毫秒。全局动画速度设置仍按现有规则生效：慢速约103.04秒、正常约82.43秒、快速约61.82秒。
- 播放期间不移动宠物窗口，不进入月下屋檐常驻状态，也不改变动作播放前的窗口缩放比例和位置。
- 选择其他动作、待机、拖动宠物、单击或双击时，继续沿用现有中断逻辑；中断后不记忆进度，下次从第一帧重新播放。
- 播放自然结束后恢复用户原先启用的基础模式，包括闲逛、鼠标注视或自主小动作。

## 固定内容顺序

组合动作严格沿用已验收视频的15段时间线：

1. 正常站立眨眼，约0.5秒；
2. 站立吃栗子；
3. 正常站立眨眼，约0.5秒；
4. 36帧影视分镜版；
5. 正常站立眨眼，约0.5秒；
6. 48帧原地展开版；
7. 正常站立眨眼，约0.5秒；
8. V9小圆月版全部动作；
9. 正常站立眨眼，约0.5秒；
10. 184月亮背景版，只播放吃栗子动作；
11. 正常站立眨眼，约0.5秒；
12. 232月亮背景版，只播放吃栗子动作；
13. 正常站立眨眼，约0.5秒；
14. 满屏月面背景版，只播放吃栗子动作；
15. 正常站立眨眼，约0.5秒。

视频中的1600×900桌面截图、任务栏、编码压缩和静音音轨不属于宠物动作，不写入图集。动作只使用每段原始192×208透明画布；人物、屋檐、月亮和特效仍作为同一固定画布播放，因此不会发生逐帧缩放或中心漂移。

## 帧压缩与时间还原

已验收视频为30fps、2473个输出帧、约82.433秒。视频为了保持时长，同一源画面会连续占用多个输出帧；直接把2473帧全部写入图集会造成无意义膨胀。

构建器按视频计划重新计算每个输出帧对应的原始动作帧，并把连续相同的源画面合并为一个图集帧。合并结果为448个连续帧：

- 眨眼片段：每段7帧，共8段；
- 站立吃栗子：10帧；
- 36帧影视分镜版：36帧；
- 48帧原地展开版：48帧；
- V9小圆月版：166帧；
- 三个月亮背景吃栗子版本：每版44帧。

每个合并帧的 `frameDurations` 由30fps累计时间边界取整得到，不能简单统一为固定 `frameMs`。448项时长之和必须严格等于82433毫秒；片段边界、首尾帧和视觉顺序必须与视频时间线一致。

## 图集布局与容量

现有南宫婉图集为16列×34行，每格192×208，共544格，尺寸3072×7072。新动作从第34行第0列开始，连续追加448格，正好增加28行：

- 新图集布局：16列×62行；
- 新图集尺寸：3072×12896；
- 总格数：992；
- 总像素数：39,616,512。

上述结果同时低于当前宠物规范的2048格上限、50,000,000像素上限和WebP单边16383像素上限。无需拆分第二张图集，也无需改变192×208统一图集格式。

新图集继续输出到南宫婉正式资源的 `spritesheet.webp`。修改前的正式图集必须复制为带版本说明的历史 WebP 保留，不覆盖已有的 `spritesheet-moonlit-rooftop-v1.webp` 和 `spritesheet-moonlit-chestnut-v2.4.1-legacy.webp`。

## 通用动作展示兼容

当前“动作展示”会依次播放所有菜单可见或允许自主触发的 `interaction` 动作。若只增加菜单项，新动作会在通用展示末尾再次播放整套82秒内容，形成重复。

动作规范新增可选布尔字段：

```json
"includeInShowcase": false
```

规则如下：

- 字段缺省时为 `true`，所有现有宠物包保持原行为；
- 只控制通用“动作展示”的收录，不影响右键菜单显示、手动播放和自主权重；
- `completeShowcase` 设置为 `false`；
- 非布尔值、镜像动作中的非法组合及未知字段继续在宠物包加载时失败关闭；
- 菜单详情明确说明该动作仅供手动完整观看，不参加随机动作、自动小动作和通用动作展示。

实现层在 `PetActionDefinition`、宠物JSON解析器和 `AnimationCatalog.showcase_actions()` 中贯通该字段，并更新新增宠物规范文档。

## 构建与可复现性

新增专用构建脚本，从现有展示视频的时间线配置和已保留的原始动作素材生成448帧序列。构建过程不得从MP4反向截图，因为有损编码会污染透明边缘和色彩；必须复用生成视频时使用的原始WebP帧及相同的源帧索引算法。

构建器先写入临时文件，完成以下检查后再原子替换正式资源：

- 当前正式图集哈希与预期输入一致；
- 现有544格逐像素保持不变；
- 新增448格的顺序、尺寸和Alpha通道正确；
- 448项帧时长总和为82433毫秒；
- 图集尺寸、总格数和总像素满足宠物规范；
- `pet.json` 能被正式注册器加载；
- 失败时不覆盖现有正式图集和JSON。

构建脚本必须可重复执行。输入未变时，再次执行得到相同的动作帧、JSON配置和资源哈希，不得重复向图集尾部追加同一序列。

## 测试与验收

至少覆盖以下自动测试：

- `includeInShowcase` 缺省为真、显式为假以及非法类型；
- 菜单可见但 `includeInShowcase=false` 的动作不进入 `showcase_actions()`；
- `completeShowcase` 出现在南宫婉右键动作列表；
- `completeShowcase` 不进入自主动作、随机动作和通用动作展示；
- 动作包含448帧、只播放一次、正常速度总时长82433毫秒；
- 448帧可以跨越28行连续寻址，最后一帧位置正确；
- 新图集旧区域逐像素不变；
- 15段边界和每段首、中、末抽样帧与已批准源素材一致；
- 动作自然结束和被用户中断后都能恢复基础模式；
- 现有宠物包与旧版JSON继续正常加载；
- 聚焦测试和全套测试全部通过。

生成一张15列接触表，每列显示一个片段的代表帧，并另外导出15段边界首帧和末帧供人工检查。重点确认没有桌面背景、任务栏、文字、黑帧、棋盘格、透明边缘污染、人物缩放跳变或屋檐锚点漂移。

## 安装与保留

验收通过后：

- 更新本机桌面灵伴正式安装目录和安装包；
- 保留当前可运行版本及修改前南宫婉正式图集的备份；
- 不删除任何历史月下屋檐WebP或此前生成的视频；
- 本设计阶段不自动上传GitHub或Gitee，上传需用户另行确认。

## 非目标

- 不把桌面背景或视频文件直接嵌入宠物。
- 不让该82秒动作自动随机出现。
- 不替换现有V9月下屋檐状态或站立吃栗子动作。
- 不改变其他动作的权重、冷却、名称、帧数或播放速度。
- 不引入第二张运行时图集或通用跨图集播放器。
- 不删除或重命名历史素材。
