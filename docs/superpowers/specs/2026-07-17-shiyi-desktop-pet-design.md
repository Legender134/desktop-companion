# 十一独立桌面宠物设计规格

日期：2026-07-17  
状态：用户已确认交互、架构、安装方式与测试范围

## 1. 目标

把现有 Codex v2 宠物“十一”改造成独立的 Windows 桌面宠物。程序直接在桌面运行，不依赖 Codex、Python、Qt 或其他预装软件，并通过正式安装程序交付。

现有 `1536×2288`、`8×11`、RGBA WebP 图集继续作为唯一动画视觉来源。桌面程序重新解释原来与 Codex 任务状态绑定的动作，使其成为通用桌面宠物行为。

目标平台为 Windows 10/11 x64。程序按当前用户安装，不要求管理员权限，不联网，不上传任何数据。

## 2. 交付形式

最终交付：

- `十一桌面宠物安装程序.exe`
- 中文安装与使用说明
- SHA-256 校验文件
- 可继续开发的完整源代码

安装程序使用 Inno Setup，应用主体使用 PySide6，构建产物使用 PyInstaller 的 one-folder 模式后再封装。目标电脑只看到一个安装程序；安装后的 Python、Qt 和图像插件都位于应用安装目录中。

默认安装位置：

```text
%LOCALAPPDATA%\Programs\ShiyiDesktopPet
```

安装内容包括开始菜单快捷方式、卸载程序和当前用户开机启动。安装与运行均不提升权限。

## 3. 首次启动与设置记忆

首次启动默认值：

- 自动闲逛：关闭
- 看向鼠标：开启
- 悬停数字快捷键：开启
- 始终置顶：开启
- 开机启动：开启
- 显示大小：100%
- 动画速度：正常
- 移动速度：正常
- 初始位置：主屏幕右下方、任务栏上方

之后记住上一次退出时的：

- 自动闲逛模式
- 宠物位置和所在显示器
- 显示大小
- 动画速度与移动速度
- 看向鼠标、数字快捷键、置顶和开机启动开关

设置保存在：

```text
%APPDATA%\ShiyiDesktopPet\settings.ini
```

## 4. 动作映射

现有标准动作重新命名如下：

| 数字 | 图集状态 | 桌面行为 | 播放规则 |
|---|---|---|---|
| 1 | `idle` | 休息 | 持续循环 |
| 2 | `running-right` | 向右奔跑 | 播放一轮并向右移动 |
| 3 | `running-left` | 向左奔跑 | 播放一轮并向左移动 |
| 4 | `waving` | 招手 | 播放两轮后返回原模式 |
| 5 | `jumping` | 跳跃 | 播放一轮后返回原模式 |
| 6 | `failed` | 撒娇翻肚 | 播放一轮，最后一帧停留约 1 秒 |
| 7 | `waiting` | 期待 | 播放一轮后返回原模式 |
| 8 | `running` | 原地巡视 | 播放一轮，不移动窗口 |
| 9 | `review` | 好奇观察 | 播放一轮后返回原模式 |
| 0 | — | 随机动作 | 从 4–9 中选择，避免意外位移 |

右键菜单的“动作”子菜单列出上述 9 个动作、随机动作，以及“观察方向”子菜单中的全部 16 个方向。

观察方向保持 v2 图集的固定顺时针顺序：

```text
000, 022.5, 045, 067.5, 090, 112.5, 135, 157.5,
180, 202.5, 225, 247.5, 270, 292.5, 315, 337.5
```

## 5. 鼠标与键盘交互

### 5.1 鼠标

- 左键按住并拖动：移动宠物。
- 左键双击：触发跳跃。
- 中键单击：触发随机动作。
- 右键单击：打开完整菜单。
- 光标靠近且没有更高优先级动作时：十一使用 16 个方向看向光标。

透明窗口只在当前帧的非透明宠物像素上参与命中测试。宠物外接矩形中的透明区域不阻挡后方桌面或应用点击。

### 5.2 数字快捷键

使用 Windows 低级键盘钩子监听主键盘与小键盘 `0–9`。只有同时满足以下条件时才触发：

1. “悬停数字快捷键”已开启；
2. 光标位于宠物窗口范围内；
3. 光标对应当前帧的非透明像素。

满足条件时数字键的按下与抬起事件都由宠物消费，不再传递给当前前台应用；其他情况完全透传。钩子回调只投递动作事件，不直接更新 UI。

## 6. 自动看向鼠标

以宠物可见区域中心到光标位置的屏幕向量计算角度：`000` 为正上方，角度顺时针增加。角度量化到最近的 22.5 度方向。

光标位于中心死区时显示休息动画，避免频繁抖动。方向切换需要最短稳定时间，并受行为优先级控制。

## 7. 自动闲逛

自动闲逛开启时，十一在当前显示器的 `availableGeometry` 内活动，因此不会进入任务栏区域。

闲逛周期：

1. 随机休息一段时间；
2. 选择左或右目标位置；
3. 播放对应奔跑动画并移动窗口；
4. 到达目标或边缘后停止；
5. 以受控概率触发招手、跳跃、翻肚、期待、巡视或观察；
6. 返回休息并开始下一周期。

任何手动动作、拖动或菜单操作立即中断闲逛。手动动作完成后恢复先前模式。移动速度随用户设置和显示缩放调整，但不得越过屏幕可用区域。

## 8. 行为状态机

行为优先级固定为：

```text
拖动 > 手动触发动作 > 自动闲逛 > 看向鼠标 > 休息
```

主要状态：

- `IDLE`
- `GAZE`
- `MANUAL_ACTION`
- `WANDER_WAIT`
- `WANDER_MOVE`
- `DRAGGING`
- `SHUTTING_DOWN`

只有 `BehaviorController` 可以切换行为状态。窗口、键盘钩子、托盘和定时器只提交意图事件，避免多处直接修改动画导致竞态。

## 9. 组件边界

### `AnimationCatalog`

- 读取 v2 WebP 图集；
- 验证尺寸、格式和行列；
- 按 `192×208` 单元格切分帧；
- 保存标准动作与 16 个观察方向的帧、时序和 alpha 命中掩码。

### `PetWindow`

- 透明、无边框、默认置顶；
- 绘制当前帧；
- 根据 alpha 掩码更新可点击区域；
- 处理拖动、双击、中键和右键；
- 不包含行为决策。

### `BehaviorController`

- 实现状态机和优先级；
- 控制动作播放、循环、返回模式和手动打断；
- 向窗口发布当前帧和位置变化。

### `GazeController`

- 计算光标角度、死区、量化方向和稳定时间；
- 只向行为控制器请求观察方向。

### `WanderController`

- 选择当前显示器、目标位置、移动方向和随机动作；
- 使用屏幕可用区域做边界约束。

### `KeyboardHook`

- 安装和卸载 `WH_KEYBOARD_LL`；
- 判断数字键、功能开关和 alpha 命中；
- 通过线程安全信号提交动作编号；
- 非命中条件调用下一个钩子。

### `SettingsStore`

- 读写 INI 设置；
- 对损坏、缺失或越界值使用默认值；
- 版本化设置结构，允许后续升级。

### `TrayController`

- 提供动作、设置、恢复位置、显示宠物和退出入口；
- 右键宠物菜单与托盘菜单共享同一套动作命令。

### `StartupManager`

- 管理 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`；
- 注册已安装程序的绝对路径与 `--startup` 参数；
- 菜单开关与实际注册表状态保持一致。

### `SingleInstanceGuard`

- 使用 Windows 命名互斥体防止重复实例；
- 使用具名 `QLocalServer`/`QLocalSocket` 传递“显示并置前”消息；
- 第二次启动连接现有实例、发送消息，然后退出。

## 10. 多显示器与位置恢复

- 保存窗口中心相对于显示器可用区域的位置与显示器标识。
- 启动时优先恢复到原显示器。
- 原显示器不存在、分辨率变化或位置完全不可见时，将宠物夹紧到最近可用显示器。
- “回到屏幕中央”使用光标所在显示器。
- 自动闲逛不跨显示器边界；用户可以拖动到另一块屏幕后继续闲逛。

## 12. 安装、升级与卸载

安装程序：

- 按当前用户安装，无 UAC；
- 安装应用与 Qt 必需插件；
- 创建开始菜单快捷方式；
- 默认写入开机启动；
- 首次安装后可选择立即运行；
- 覆盖安装时关闭旧进程并保留用户设置。

卸载程序：

- 请求现有实例退出；
- 删除开机启动注册值；
- 删除安装目录、设置和日志；
- 不修改原始十一照片、Codex 宠物包或其他应用数据。

## 13. 错误处理与日志

日志目录：

```text
%LOCALAPPDATA%\ShiyiDesktopPet\logs
```

采用轮转日志，单文件最大约 1 MB，保留最近 3 份。

错误策略：

- 图集缺失、损坏或契约不符：显示错误对话框并退出，不留下隐形进程。
- 设置文件损坏：记录警告并恢复默认值。
- 键盘钩子安装失败：关闭数字快捷键，显示托盘通知，其余功能继续运行。
- 托盘不可用：宠物右键菜单仍提供全部设置和退出。
- 已保存位置不可见：自动恢复到可见区域。
- 未处理异常：写入日志，尝试移除键盘钩子和托盘图标后退出。

## 14. 隐私与安全

- 程序没有网络请求、遥测、账号或自动更新。
- 键盘钩子只识别数字键的按下/抬起，不记录文本，不写入日志。
- 数字事件只在宠物非透明像素命中时消费。
- 开机启动只写当前用户的 `Run` 注册值。
- 安装和运行不要求管理员权限。

## 15. 测试策略

### 单元测试

- 9 个标准动作的帧数、循环次数与返回规则；
- 数字到动作的映射；
- 行为状态优先级与手动打断；
- 角度到 16 个方向的量化与中心死区；
- 自动闲逛目标选择、边界转向与速度；
- 多显示器位置保存、恢复和夹紧；
- 设置默认值、保存、损坏恢复和版本迁移；
- alpha 像素命中与透明区域透传；
- 单实例与启动参数解析。

### 资源契约测试

- 图集必须是 RGBA WebP、`1536×2288`、`8×11`；
- PyInstaller 产物必须包含 Qt WebP 图像插件，并能在干净环境读取图集；
- 74 个必需帧非空；
- 14 个未使用槽完全透明；
- 标准动作帧数与 Codex v2 图集契约一致；
- 16 个观察方向均存在且顺序固定。

### 集成测试

- 键盘钩子只在非透明命中时消费数字；
- 拖动、双击、中键、右键菜单和托盘菜单触发正确命令；
- 开机启动开关与注册表一致；
- 第二实例不会产生第二只宠物；
- 异常设置与离屏位置能自动恢复；
- 程序在无 Codex、无 Python、无 Qt 的干净环境中启动。

### 安装验收

- 正常安装、启动、退出和卸载；
- 默认开机启动与菜单关闭后不再启动；
- 覆盖安装保留设置；
- 安装程序不请求管理员权限；
- 卸载后无 Run 注册值或残留进程；
- 安装包与关键文件 SHA-256 可复核。

### 人工视觉验收

- 透明边缘无底色框或明显色边；
- 透明区域不拦截桌面点击；
- 动作不裁切、不跳帧、不错误缩放；
- 左右奔跑方向与位移一致；
- 16 个方向看向鼠标自然，无明显抖动或逆序；
- 多显示器、不同 DPI 与四档大小下保持清晰；
- 右键菜单、托盘和数字触发可在正常办公场景中使用。

## 16. 验收标准

只有全部满足时才算完成：

1. 在未安装 Codex、Python 或 Qt 的 Windows 10/11 x64 环境中可通过安装程序运行。
2. 安装程序按当前用户安装，默认启用开机启动，并提供干净卸载。
3. 十一使用现有经过验证的 v2 图集，9 个标准动作与 16 个方向全部可触发。
4. 右键菜单、悬停数字键、拖动、双击、中键、看向鼠标和自动闲逛均可用。
5. 自动闲逛、位置、大小、速度和开关状态能跨重启恢复。
6. 数字键只在宠物非透明像素命中时被消费，其他键盘输入不受影响。
7. 透明区域可点击穿透，宠物身体可正常交互。
8. 程序不会出现重复实例、不可退出的后台进程或离屏无法找回的宠物。
9. 不联网、不记录键盘文本、不要求管理员权限。
10. 单元、资源契约、集成、安装和人工视觉验收全部通过。

## 17. 非目标

本期不包含：

- macOS 或 Linux 版本；
- 在线更新、账号、云同步或遥测；
- 新绘制动作、音效、语音或粒子特效；
- 桌面组件商店或多宠物管理；
- 修改现有 Codex 宠物安装包。
