# 南宫婉纯动作展示视频 V2 设计

## 目标

重做一支只展示南宫婉桌面灵伴动作的横屏视频。视频不讲制作过程，不组织故事，不解释版本，不加入标题、字幕、说明卡、投票、旁白或音乐。观众看到的内容只有用户指定的真实桌面背景、居中的桌面宠物以及七段动作。

## 输出

- 画面尺寸：1600×900，与用户提供的桌面截图完全一致。
- 帧率：30fps，恒定帧率。
- 视频编码：H.264 High、yuv420p、SAR 1:1、`+faststart`。
- 音频：保留 48kHz 双声道静音 AAC，便于以后追加声音；本版听不到任何声音。
- 预计时长：约 82.43 秒。最终时长按 30fps 整帧量化，但不得通过缩放动作速度凑时长。
- 输出目录：Git 已忽略的 `work/nangongwan-action-showcase-v2/`，不进入安装包，也不自动上传仓库。

## 唯一背景

- 使用用户提供的截图：`C:\Users\23644\AppData\Local\Temp\codex-clipboard-fa2f4101-2de0-4c4a-a1c9-01fc1c2a4412.png`。
- 原图为 1600×900 RGB，底部 Windows 任务栏必须完整保留。
- 构建前把原图复制为输出目录中的只读输入副本，并记录 SHA-256；后续渲染只读取该副本，避免临时文件消失或被替换。
- 不重绘、不模糊、不调色、不裁切、不加渐变、不替换任务栏，也不叠加此前自制的蓝色桌面背景。

## 宠物位置与大小

- 所有动作都以现有桌面灵伴 100% 原生尺寸显示。
- 每帧宠物画布保持 192×208，不放大也不缩小。
- 画布中心严格放在视频中心 `(800, 450)`；对应左上角固定为 `(704, 346)`。
- 普通站立、36帧版、48帧版、V9和三种月亮背景都使用同一画布几何，不因月亮或屋檐扩大显示尺寸。
- 透明区域按 alpha 正常叠加到桌面截图，不显示棋盘格、黑底或白边。

## 播放顺序

共有七段主动作和八段站立眨眼缓冲。顺序固定为：

1. 正常站立眨眼，约 0.5 秒；
2. 站立吃栗子，完整播放一次；
3. 正常站立眨眼，约 0.5 秒；
4. 36帧影视分镜版，完整播放一次；
5. 正常站立眨眼，约 0.5 秒；
6. 48帧原地展开版，完整播放一次；
7. 正常站立眨眼，约 0.5 秒；
8. 小圆月 V9 版，按现有预览序列完整播放入口、九种居民动作和离开；
9. 正常站立眨眼，约 0.5 秒；
10. 184像素完整大圆月版，只播放 `rooftopChestnut`；
11. 正常站立眨眼，约 0.5 秒；
12. 232像素越界巨月版，只播放 `rooftopChestnut`；
13. 正常站立眨眼，约 0.5 秒；
14. 满屏月面版，只播放 `rooftopChestnut`；
15. 正常站立眨眼，约 0.5 秒后结束。

## 动作时序

- 主动作必须使用各自 JSON 中的 `frameDurations`，不得统一改成等间隔帧。
- 站立吃栗子：10帧，2080毫秒。
- 36帧影视分镜版：36帧，9100毫秒。
- 48帧原地展开版：48帧，9600毫秒。
- 小圆月 V9 全动作序列：166帧，30680毫秒。
- 三种新月亮：各44帧、8990毫秒，动作帧序列和时序相同，只允许月亮背景不同。
- 眨眼缓冲使用现有 `idle` 动作中的正常站立和闭眼帧，重新安排为15个视频帧、精确0.5秒；必须形成“睁眼→眨眼→睁眼”，不能只是静止站立，也不能截取到呼吸动作的突兀中间帧。
- 30fps不能精确表示部分10毫秒时长。每段主动作独立按累计时间映射到视频帧，保留首尾帧并限制单帧误差小于一个视频帧；三个月亮版本必须得到完全相同的输出帧数和帧映射。

## 转场

- 所有片段均直接硬切。
- 不使用交叉淡化、缩放、推拉、黑场、空白桌面、闪白或转场音效。
- 眨眼缓冲本身就是唯一转场，因此动作结束后直接切到站立眨眼，眨眼结束后直接切入下一段动作。

## 素材边界

- 允许使用本机历史素材库中的公开生成资源：站立吃栗子、36帧、48帧、V9小圆月、184月亮、232月亮和满屏月面图集及其 JSON。
- 禁止读取或引用 `07-private-anime-reference-DO-NOT-PUBLISH/`。
- 不使用旧版制作纪录片中的卡片、字幕、接触表、蓝色背景或反馈文案。
- 不覆盖历史图集，不修改当前安装资源；视频构建只生成新的本机输出。

## 构建结构

- 新建一套独立的 V2 展示编排器；复用现有安全的图集读取、逐帧时长和 FFmpeg 错误传播能力。
- 背景合成函数改为接收用户截图，按固定 `(704, 346)` alpha 叠加192×208帧。
- 先生成15段无音频、1600×900、30fps中间片段，再按固定顺序无重编码或同参数重编码拼接；最后加入静音 AAC。
- 新输出不得覆盖此前的 `master-v1-no-voice-1920x1080.mp4`，便于对比和回退。

## 验收

- 视频中不得出现任何可见文字叠加；背景截图本身已有的任务栏文字和图标不算叠加。
- 每张编码前合成帧在宠物192×208画布以外必须与输入截图逐像素一致；H.264编码后的画面允许正常的yuv420p压缩误差，但背景不得出现肉眼可见的变色、裁切或模糊。
- 每一帧宠物画布边界固定为左上角 `(704, 346)`，不得漂移。
- 七段主动作均只出现一次且完整；不得回放、慢放或遗漏。
- 开头、六处中间和结尾共八次眨眼，均为15帧。
- 三种月亮动作的输出帧数、角色位置和时间映射完全一致。
- 视频无棋盘格、黑帧、白边、透明漏底、人物突然缩放或字幕残留。
- 自动测试验证顺序、片段帧数、中心坐标、背景外区域像素、编码和静音轨；另抽取每段首中尾帧组成接触表供人工检查。

## 审片门

V2 首稿生成后，只请用户检查四件事：背景是否就是指定桌面、角色是否真正处于画面正中心、100%大小是否合适、七段动作与八次眨眼的顺序是否正确。用户确认前不追加文字、音乐、配音、封面、竖屏版或上传仓库。
