# 桌面灵伴 2.4.0 注视模式验收记录

## 本版变化

- 将宠物包注视密度扩展为 16、32 或 64 帧；南宫婉使用 64 帧、每 5.625° 一档的伪连续注视。
- 保留 16 张顺时针审定姿态作为不可替换的硬锚点，相邻锚点间使用三张 RIFE 神经补帧过渡，不在运行时透明混合。
- 使用约 110 毫秒的圆周最短路径平滑和每秒约 360°的转向上限，让大角度变化依次经过中间姿态。
- 新增“鼠标活动时（推荐）”与“始终看向鼠标”两档注视方式。
- 修复自动闲逛优先级高于看向鼠标、导致勾选闲逛后注视失效的问题。
- 设置 schema 从 4 升至 5；旧设置默认迁移为“鼠标活动时”。

## 自动验证

- 角度计算、跨 0° 最短路径、中心死区保持与无效响应时间。
- 任意角度到最近注视帧的动态映射、5.625°边界、0° 环绕和大角度限速。
- 注视优先于闲逛，静止 8 秒后恢复闲逛，鼠标再次移动立即夺回控制。
- 始终注视会暂停闲逛和自主动作。
- 菜单互斥单选、设置保存与旧 schema 迁移。

## 人工验收步骤

1. 切换到南宫婉，开启“看向鼠标”，注视方式选“鼠标活动时（推荐）”。
2. 用鼠标缓慢绕人物一圈，确认64个方向按每 5.625° 递进，正上、右上、右、右下、下、左下、左、左上顺序正确，无逆序跳变和明显跳档。
3. 开启自动闲逛并停止移动鼠标 8 秒，确认宠物开始闲逛；移动鼠标，确认当前闲逛立即停止并恢复注视。
4. 关闭自动闲逛、开启自主小动作，再静止 8 秒，确认只播放原地动作；鼠标移动后恢复注视。
5. 两项都关闭后静止 8 秒，确认保持普通待机。
6. 选择“始终看向鼠标”，等待超过 8 秒，确认不会进入闲逛或自主动作。
7. 退出并重新启动，确认注视方式仍保持选择值。

## 素材复核说明

南宫婉的注视素材不再修改或重排旧稿，而是从全新正面母版重新绘制。右半圆的 0°、22.5°、45°、67.5°、90°、112.5°、135°、157.5°、180°分别独立绘制和审图；左半圆七档由对应的新绘姿态严格镜像。七组对称角逐像素完全一致，16 张关键姿态均不重复，并固定放在64帧环的每第4帧。

第一版普通运动估计补帧因多个面部角度出现明显模糊而被淘汰。正式64帧环改用 RIFE anime 模型在每对锚点间补出 5.625°、11.25°、16.875°三个中间位置，再逐帧回填原始锚点。新图集从第20行开始连续占用4行，64个单元格与审定帧完全一致；前19行其他动作逐像素保持不变。

素材审图仍以“方向能否一眼读出”“相邻姿态是否沿圆周递进”和“补帧是否保持五官清晰”为准。程序只显示清晰原帧，并以圆周最短路径限速切换，不使用会产生双影的透明混合。
