# 桌面灵伴 2.4.0 注视模式验收记录

## 本版变化

- 保留宠物包规定的 16 张顺时针注视关键姿态，不生成有双影的混合帧。
- 使用约 110 毫秒的圆周最短路径平滑和每秒约 360°的转向上限，让大角度变化依次经过中间姿态。
- 新增“鼠标活动时（推荐）”与“始终看向鼠标”两档注视方式。
- 修复自动闲逛优先级高于看向鼠标、导致勾选闲逛后注视失效的问题。
- 设置 schema 从 4 升至 5；旧设置默认迁移为“鼠标活动时”。

## 自动验证

- 角度计算、跨 0° 最短路径、中心死区保持与无效响应时间。
- 任意角度到最近关键帧的映射、0° 环绕和大角度限速。
- 注视优先于闲逛，静止 8 秒后恢复闲逛，鼠标再次移动立即夺回控制。
- 始终注视会暂停闲逛和自主动作。
- 菜单互斥单选、设置保存与旧 schema 迁移。

## 人工验收步骤

1. 切换到南宫婉，开启“看向鼠标”，注视方式选“鼠标活动时（推荐）”。
2. 用鼠标缓慢绕人物一圈，确认方向按正上、右上、右、右下、下、左下、左、左上连续变化，无逆序跳变。
3. 开启自动闲逛并停止移动鼠标 8 秒，确认宠物开始闲逛；移动鼠标，确认当前闲逛立即停止并恢复注视。
4. 关闭自动闲逛、开启自主小动作，再静止 8 秒，确认只播放原地动作；鼠标移动后恢复注视。
5. 两项都关闭后静止 8 秒，确认保持普通待机。
6. 选择“始终看向鼠标”，等待超过 8 秒，确认不会进入闲逛或自主动作。
7. 退出并重新启动，确认注视方式仍保持选择值。

## 素材复核说明

南宫婉 16 张关键姿态的顺时针排列正确，但正上方、左下相邻档和左上接近正上方的个别差异较弱。替代生成稿出现衣服、身形及左右方向漂移，因此未替换正式角色素材；本版优先保持角色造型一致，并通过运行时过渡改善连续性。
