# 动作分组、视线门槛与闲逛强度

本说明记录动态宠物行为扩展，适用于支持 v3 宠物包的开发版运行时。

## 自动动作分组

`interaction` 可选填 `autoplayGroup`。上一次随机动作具有非空组名时，下一次随机选择会优先排除相同组；只有没有其他可用互动动作时才允许回退到同组。每个动作自身的 `cooldownMs` 和禁止同一动作连续重复的规则继续有效。

南宫婉七套术法统一使用 `autoplayGroup: "spell"`，因此随机术法后至少穿插一套日常动作。菜单手动播放不受分组限制。

## 视线动作门槛

只有当前宠物真正提供 16 帧 `role: "gaze"` 时，“看向鼠标”才会让自主小动作等待鼠标连续静止 8 秒。不支持 `gaze` 的宠物即使旧设置中保留 `gaze_enabled = true`，也按无视线模式使用 15–35 秒随机间隔。

南宫婉从 2.3.1 起提供完整的 16 方向注视帧，按正上方开始、顺时针每 22.5° 一帧排列。注视只改变眼神和轻微头部朝向，不出现在动作菜单，也不参与随机动作。

## 闲逛强度

设置文件 schema 为 4，新增 `wander_intensity`：

| 值 | 菜单名称 | 等待时间 | 单次目标距离 |
| --- | --- | --- | --- |
| `quiet` | 安静 | 8–18 秒 | 不超过当前屏幕可移动宽度的 25% |
| `standard` | 标准 | 2–6 秒 | 保持原有全屏目标范围 |
| `active` | 活跃 | 1–3 秒 | 全屏目标范围 |

旧设置升级时采用 `standard`，其他宠物、位置、速度、缩放和开关保持原值。

## 验收重点

1. 连续执行多次随机动作，任意两套 `spell` 之间必须出现非 `spell` 动作。
2. 切换到南宫婉并开启“看向鼠标”，移动鼠标经过上下左右和对角方向时应选中对应注视帧；关闭后恢复普通待机。
3. 三档闲逛菜单是互斥单选，退出重启后保持。
4. 安静档的目标始终留在当前显示器内，且实际直线距离不超过计算上限。

## 2.3.0 验证结果

- 针对动作注册、设置迁移、菜单、视线门槛、闲逛规划和应用调度的 88 项测试通过。
- 全部源码测试：180 项通过。
- `pip check`：无损坏依赖。
- 本机设置已从 schema 3 迁移到 schema 4，原有宠物、开关、位置、缩放和速度保持不变。
