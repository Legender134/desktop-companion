# 桌面灵伴 2.4.1“月下含栗”验收记录

## 本版变化

- 南宫婉新增 `moonlitChestnut`（菜单名“月下含栗”）：36 帧、正常速度 9.1 秒、单次播放、90 秒自动冷却。
- 右键菜单可以随时手动播放；手动播放不受自动冷却限制。
- 开启“自主小动作”后，新动作的配置权重为 5；其余原地动作权重同比放大后三者总和为 101，因此基础名义概率为 `5/101`，约 4.95%。
- 旧 `tasteCake` 的 10 帧和动作 ID 保留，但不再出现在菜单、自主动作池和动作展示中。
- 动作展示只播放菜单可见或允许自主触发的原地动作，跳过同时隐藏且无权重的休眠/彩蛋动作。

## 动漫镜头一致性复核

- 远景使用巨大且完整/接近完整的月轮与深色屋檐，人物以小比例侧坐在飞檐最外缘。
- 连续推近时月轮同步放大，圆轮边缘逐步越出画面；坐姿中景只看见巨大局部月面。
- 御物、栗糕和嘴部特写不显示月轮，只保留冷色月光；这一点与动画片段一致。
- 特写结束后回到巨大局部月面下的飞檐坐姿，再退回远景淡出。
- 人物始终保持最新蓝银造型；全身镜头中臀部落在飞檐外缘、双腿屈向画面左侧，不出现站姿或悬浮站立。
- 栗糕为金黄色有棱纹的小块；紫色灵力只围绕手指和栗糕，没有法阵、雷电、花瓣或额外术法。
- 关键镜头使用干净切镜而非半透明双图叠化，逐帧审图未出现双人、双脸或重影。
