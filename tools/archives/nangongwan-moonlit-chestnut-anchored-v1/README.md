# 南宫婉“月下含栗”原地屋檐版归档

这是 2026-07-21 完成的 48 帧、9600 毫秒候选版。它已通过完整源码测试，画面连续，但“为了吃栗糕而临时坐下、随后立即起身”的桌面动作动机不够自然，因此不直接作为正式发布版。

本目录用于完整保留候选，后续重做不得覆盖：

- `spritesheet.webp`：包含该候选动作的完整南宫婉活动图集。
- `pet.json`：与图集对应的 48 帧和逐帧时长配置。
- `moonlit-chestnut-9600ms.gif` / `.mp4`：真实时长预览。
- `audit-48.png`：48 帧接触表。
- `source-assets/`：该候选使用的透明源素材。
- `scripts/`：参考板、图集构建和预览诊断脚本。

若要恢复候选，应同时恢复 `spritesheet.webp` 和 `pet.json`，不能只替换其中一个文件。此归档不由运行时读取，也不随安装包自动安装。
